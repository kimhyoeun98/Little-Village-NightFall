# Little Village: Nightfall

귀여운 동물 마을을 배경으로 한 2~12인 멀티플레이 파티 게임 기획 저장소입니다.

게임의 중심은 긴 토론이 아니라 **낮에 준비하고, 밤에 숨고 움직이며, 아침에 실제 목격을 토대로 짧게 추리하는 것**입니다.

## 문서 안내

- [기획 기준서](docs/GAME_DESIGN_BASELINE.md): 이미 확정된 원칙과 아직 미정인 항목을 분리한 기준 문서
- [코어 루프 제안서](docs/CORE_LOOP_PROPOSAL.md): 첫 번째 마을 모드 플레이테스트를 위한 가설과 비교안
- [의사결정 백로그](docs/DECISION_BACKLOG.md): 앞으로 결정할 항목, 순서, 검증 질문

## 문서 상태 표기

- **확정**: 원 기획에서 이미 결정된 내용. 합의 없이 변경하지 않는다.
- **제안**: 플레이테스트를 위한 후보안. 확정 사항이 아니다.
- **대안**: 제안과 비교할 수 있는 다른 방향.
- **미정**: 추가 논의나 테스트가 필요한 내용.

현재 단계는 **프리프로덕션 / 기획 가설 수립**이다.
